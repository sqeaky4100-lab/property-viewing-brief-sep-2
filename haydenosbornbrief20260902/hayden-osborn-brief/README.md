# Hayden & Osborn at 3 PM — viewing brief

Static site, no build step. Deploy: unzip, then drag this folder onto https://vercel.com/new (framework preset: Other). Or `npx vercel` inside the folder.

All photos are embedded in index.html as data URIs (sourced from the Zillow listing pages for zpid 72291807 and 72291763), so nothing loads from third-party hosts.
